BINTI BIRTHDAY SURPRISE WEBSITE
===============================

এই ZIP-এ আছে:
- index.html — ওয়েবসাইটের মূল পেজ
- style.css — Dark Romantic Surprise ডিজাইন
- script.js — Surprise button ও confetti animation
- README_BN.txt — ব্যবহারের নির্দেশনা

Windows 11 + VS Code-এ চালানোর নিয়ম
-----------------------------------
১. ZIP ফাইলটি Downloads থেকে খুঁজে বের করুন।
২. ZIP-এর ওপর Right-click করে "Extract All..." নির্বাচন করুন।
৩. Extract করা Binti_Birthday_Surprise ফোল্ডারটি খুলুন।
৪. VS Code চালু করুন।
৫. VS Code-এ File > Open Folder... গিয়ে ওই ফোল্ডারটি নির্বাচন করুন।
৬. index.html ফাইলটি খুলুন।
৭. সহজ উপায়: index.html-এ Right-click > Reveal in File Explorer, তারপর ফাইলটিতে double-click করুন।
   এটি Chrome-এ খুলবে।
৮. VS Code-এর Live Server extension ইনস্টল করা থাকলে index.html-এ Right-click করে
   "Open with Live Server" ব্যবহার করতে পারেন।

নিজের মতো পরিবর্তন
------------------
- জন্মদিনের নাম বা লেখা বদলাতে index.html খুলুন।
- রং/ডিজাইন বদলাতে style.css খুলুন।
- বাটনের কাজ/animation বদলাতে script.js খুলুন।

GitHub Pages-এ প্রকাশ করতে:
---------------------------
ফোল্ডারের ভেতরের index.html, style.css, script.js ফাইলগুলো আপনার GitHub repository-র
root folder-এ upload করুন। Repository Settings > Pages থেকে deployment চালু করুন।
কিছুক্ষণ পরে GitHub Pages-এর দেওয়া URL-এ সাইটটি দেখা যাবে।

নোট: এই সাইটে external music বা ব্যক্তিগত ছবি রাখা হয়নি। চাইলে নিজে ছবি যোগ করতে পারেন।
